# Data-Analytics

Maven Toys – Sales & Profitability Analysis

Project Overview

This project uses Microsoft Power BI to analyze Maven Toys' sales performance, product profitability, inventory, and business operations.

The goal is to transform raw business data into meaningful insights and interactive visualizations that support data-driven decision-making.

Tools & Technologies

  Microsoft Power BI

  Power Query

  DAX

  Data Modeling

  Data Visualization

Project Objectives

  Analyze overall sales performance.

  Identify the most profitable products.

  Explore store performance.

  Analyze inventory and product availability.

  Identify business trends and opportunities.

Files

  .pbip – Power BI Project file.

  .Report – Report pages and visualizations.

  .SemanticModel – Data model, relationships and measures.

How to Open

  Download or clone this repository.

  Open the .pbip file using Power BI Desktop.

  Refresh the data if required.
